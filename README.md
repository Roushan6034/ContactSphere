ContactSphere
A simple and efficient contact management application to store, organize, and search through your personal and professional contacts.

Features
User Authentication: Secure login and registration.
Manage Contacts: Add, edit, view, and delete contacts easily.
Search: Quickly find specific contacts from your list.
Technologies Used
Backend: Java, Spring Boot
Database: MySQL
Frontend: HTML / CSS / JavaScript
How to Run
Clone the repository:

bash

git clone https://github.com/Roushan6034/ContactSphere.git
Create a MySQL database named contactsphere_db.

Update your database username and password in application.properties (or application.yml).

Run the application:

bash

./mvnw spring-boot:run
Open your browser and go to: http://localhost:8080
